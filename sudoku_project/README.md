# Sudoku Challenge — Flask App

This project is a Sudoku game built with Flask, modern frontend UI, and Sudoku puzzle generation logic.

Features:
- Difficulty selector: Easy, Medium, Hard
- Sudoku board with live validation and invalid move highlighting
- Hint button that fills one correct cell
- Check button to highlight incorrect entries and show completion
- Timer and dark mode toggle
- Top 10 leaderboard stored in browser local storage

## Run the App Locally

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Start the Flask app:
   ```bash
   python main.py
   ```

3. Open in browser:
   - http://127.0.0.1:5000/

## Run Tests

```bash
pytest -q
```
